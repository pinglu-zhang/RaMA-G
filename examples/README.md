# Artificial examples

`genome/` contains a deterministic random reference, a query with a short insertion
and deletion, and its reverse complement. `centromere/` contains an artificial
repeated template and edited query. These files demonstrate interfaces; they are
not biological models or accuracy benchmarks. `batch/queries.txt` names the two
genome queries. Run commands from the repository root as shown in the
[quick start](../docs/quick-start.md). `pairwise/` is an installed C++ API example.
